# Python Calculator
This is a simple command-line calculator devolped in Python.It allows users to perform basic mathematical operations through an interactive menu.

## Features
- Addition
- Subtraction
- Multiplication
- Power
- Division
- Floor Division
- Modulus
- Exit option

## Requirements
- Python 3.x

## Run the Program

```bash
python3 calculator.py
```
